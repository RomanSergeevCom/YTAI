# 08_youtube — Подготовка к публикации

## Скрипты

| Скрипт | Назначение |
|--------|------------|
| `01_description.py` | Описание видео |
| `02_chapters.py` | Таймкоды глав для описания |
| `03_tags.py` | Теги |

## Выход
- `YouTube/description.txt`
- `YouTube/chapters.txt`
- `YouTube/tags.txt`

## Формат chapters.txt
```
00:00 Intro
02:30 Как начать бизнес в ОАЭ
08:15 Ошибки новичков
15:00 Налоги и лицензии
```
