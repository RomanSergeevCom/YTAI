🩹 Force refresh = the file is present at exactly the path the project records, but Premiere still shows Media offline (SSD unplugged while the project was open, importer crash). Re-imports those clips in place — nothing to find, nothing to request. Respects Scope above; ⌘S after. Truly missing files stay for Relink.
Relink = re-point offline clips to a same-name local file (best for regular media; one bin relink fixes every timeline use; ⌘S after). Restore structure = place same-name local copies at the exact paths the project records — fixes AE Dynamic-Link .aep comps & wrong-folder/renamed files that Relink can't; reopen the project afterwards so Premiere relinks by path. Editor handoffs: run Relink, then Restore structure. Not undoable.
