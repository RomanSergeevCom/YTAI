
⚠️ Три вещи **невозможно** проверить без живой Premiere, и все три уже кусали:

| | |

## Правила работы с панелью (оплачены)

- **Кнопки.** `$()` отдаёт `null`, `addEventListener` на нём бросает и гасит
  ВСЕ привязки ниже по списку. Вешать только через `on(id, fn)`.
- **Ошибка человеку.** Показал в статус-строке — обязан отдать логгеру. Буфер
  кнопки «Err» наполняется только из `logger.warn/error`.
- **Запись параметра.** Сначала `createKeyframe(value)`, мутация `getStartValue()`
  — как откат. Всегда читать обратно, сравнивать с допуском (float32!), а не `===`.
- **Lumetri.** Параметр адресовать по ИНДЕКСУ, но вслепую по индексу не писать:
  снять дамп, найти кандидатов по имени, писать и читать обратно. Готовый
  механизм — `src/adjust/colorApply.js`, не дублировать.
- **Не ломать донор.** `Input LUT` и `Look` — числовые меню, куб лежит в `Blob`.
  Значением их не поставить ничем; донор-клон это не костыль, а единственный путь.

- Проект сохраняется и при провале сборки (catch-ветка `buildIngest`) — оставлено как было.
- Экраны на странице KB 4.7 — рендер разметки; живые снимки из Premiere заменить ими.
- Гейт Verify Sync будет красным на петличках, пока не сделана ch4 5.1.
