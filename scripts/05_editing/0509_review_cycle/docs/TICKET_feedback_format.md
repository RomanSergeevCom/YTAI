## 4. ЧТО ПРЕДЛАГАЮ СДЕЛАТЬ (не догма, обсудить с Романом)

1. **Развернуть жанр.** Не «отчёт по 162 пунктам», а **«что изменилось с прошлого раза»**:
   - 🟢 **ЗАКРЫТО** — коротким списком, без подробностей: пункт + доказательство одной строкой.
   - 🔴 **ОСТАЛОСЬ** — полноценные ТЗ по канону v7 с ❌/✅/📍 и превью на кадре.
   - ⚠️ **ЖДЁТ ФОНДА** — отдельным блоком, одним списком, это не работа монтажёра.
   - 👁 «нужен глаз» — **убрать из тела** в свёрнутое приложение или в отдельный файл.
2. **Картинки обязательны** для всего, что в «ОСТАЛОСЬ» — по канону 5.6.

   ⚠️ Упирается в `shots_remote`: у YTCH12 публичной папки кадров нет намеренно (ребёнок в кадре).

   **Но выход есть, и он не требует постоянной публичности.** `insertInlineImage` берёт
   картинку по публичному HTTPS (`https://lh3.googleusercontent.com/d/{fileId}` после
   `permissions anyone`), **но при вставке копирует её ВНУТРЬ документа** — дальше ссылка
   не нужна (см. память `reference_google_docs_tabs_tables`). Значит рабочий цикл:

   ```
   залить кадр в приватную папку проекта → открыть доступ на секунды →
   insertInlineImage → снять доступ → картинка остаётся в доке, файл снова закрыт
   ```

   Доступ к самому доку и так ограничен. **Проверить на одном кадре и согласовать с Романом**
   (окно публичности короткое, но оно есть — для фильма с ребёнком решение его).
   Если не подходит — формат без картинок, но тогда таймкод+якорь обязаны заменить превью.
3. **Приоритет вместо категорий.** Сейчас секции по типу (структура/графика/вырезы) — это
   классификация кода. Человеку нужен порядок важности: сначала то, что блокирует выпуск.
4. **Сократить.** Ориентир — один экран на раздел. 162 пункта в одну вкладку не помещаются
   по-человечески; закрытые сворачиваются в счётчик со ссылкой.
