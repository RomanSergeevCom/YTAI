## 5. Решения по умолчанию (не спрашивать)

- Текст структуры живёт в двух местах: шапка «Обратная связь · v5» (короткая: главы + подглавы, ≤ 40 строк) и вкладка «Главы · v5» (полная: + фразы + варианты дизайна).

- Картинки в док — только temp_grant из закрытой папки; никаких новых публичных папок; после каждой записи — `python3 shared/doc_images.py --audit 1EhgT9F0uex0F01zWz7sIGgEivLVwubip` = 0 проблем.
