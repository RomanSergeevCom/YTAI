# agefree_plan_html_v2.py

Генератор «план сборки» для YTAgeFree 03–06 (v2 поверх `agefree_plan_html.py`). Отличия от v1:

- **Дословные полные цитаты.** Текст блоков собирается пословно из транскриптов исходников
  (не пересказ). Границы блоков (какие сегменты оставить, какие реплики режиссёра/дубли выкинуть)
  выбирает Workflow `wf_quotes.js` (агент + adversarial-verifier, 2 стадии на блок), дословный текст
  собирает `assemble.py` из выбранных индексов → verbatim гарантирован кодом, не доверием к LLM.
- **Номер + 🔗-якорь на КАЖДОМ блоке** (`#N`, `id="bN"`, копирование ссылки штатным copy-JS).
- **Сквозной хроно финала.** На каждом блоке «▶ M:SS в ролике» (running-таймкод, темп ÷1.125 = +12.5%),
  вверху KPI (клипы → блоки → отобрано сырья → итоговый хронометраж) + «Хронокарта секций».
- Хром страницы (site.css/js v14, тема core, gating) — как у остальных страниц портала.

## Пайплайн (scratchpad сессии, копии здесь для истории)
1. `reconstruct_plan.py NN` — plan.json из текущей страницы репо (+ folders/inputs).
2. `prep_packets.py` — на каждый beat окно транскрипта (packets/) + manifest.
3. Workflow `wf_quotes.js` (args `{dir,counts}`) → `blocks_result.json` (границы на блок).
4. `assemble.py blocks_result.json` → `plan_NN_final.json` (дословные цитаты + dur_sec).
5. `render_all_v2.py` → рендер в `web/ytagefree/NN/` (splice вербатим-блока «Структура папок»).

Источник истины на будущее: `plan_NN_final.json` сохранён в `{project}/00_Setup/05_Review/YTAgeFreeNN_plan.json`.
