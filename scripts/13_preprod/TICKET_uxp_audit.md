## Что нашли за день

### D. Молчаливые записи в Premiere

Коммит без исключения ≠ значение записано. ✅ Починено в `colorApply`;

## Задачи

### 1. Линтер — первым делом

```
npm i -D eslint
правила-минимум: no-undef · no-unused-vars · no-empty (кроме catch с комментарием)
                 eqeqeq · no-fallthrough
```

Гейт: `npm run lint` чистый, и он в том же прогоне, что `npm test`.
**Без этого шага остальные бессмысленны**: 25 000 строк руками не проверить, и
сегодняшний день — доказательство.

### 2. Канал «панель → человек» сделать доверенным

- ✅ (сделано) любой `setAdjustStatus(..., 'error')` → в буфер отчёта;
- то же для `setIngestStatus`, `setAssemblyStatus`, `setPartsStatus`, `setScreensStatus`
  и всех остальных — сейчас связь есть только у `adjust`;
- в отчёт добавить **стек** последней ошибки, а не только сообщение;
- правило: у ошибки ровно один источник истины, и это логгер.

### 3. Инвариант версии

```
PANEL_VERSION — единственная. Поднимать при КАЖДОЙ правке index.js/index.html/src/.
Тест: в репозитории не должно быть второй строки вида v\d+\.\d+\.\d+
```

### 4. Запись параметров: свежий кейфрейм первым

Перенести в `setEffectParam` (`adjustmentBuilder.js:423–556`, мутация первая —
строка 496 «Path A») то, что уже сделано в `colorApply.setParamAtIndex`:
порядок путей (`createKeyframe` → мутация), допуск на float32 вместо `===`,
обязательное чтение обратно. Снять дефекты **D** и **E** одной правкой.

### 5. Readback останавливает

`READBACK: … stray items present` обязан возвращать провал сборки и гасить
«built ✓», а не печататься в лог. Сегодня по такому логу проект был сохранён
и отдан дальше.

### 6. Привязки и формы данных

- все 89 привязок через `on()`; тест «каждый `id` из привязок есть в разметке»
  (сейчас сходится, но держится на честном слове);
- `collectVideoClipItems` — либо возвращать сырые айтемы, либо назвать обёртку так,
  чтобы её нельзя было принять за айтем (`{ trackItem, meta }`).

### 7. Проверка синхрона в панели

Кнопка **Verify Sync** — см. `TICKET_ch4_sync_truth.md`, задача 5.3. Вердикт в
кадрах сразу после Build.
