## 1. Механизм дефекта

Ингест хранит настенное время каждого клипа. Билдер при укладке **выбрасывает
паузы между дублями** — и вот тут расходятся видео и звук:

```

            └───1264────────────┘

ТАЙМЛАЙН — ВИДЕО: пауза выброшена, всё сдвинулось влево на 28.8
 0          69.7                161.9
 ├─1263─────┼───1264────────────┼─1265──────────────────────
            ↑ встал вплотную, а не на 98.5

ТАЙМЛАЙН — ПЕТЛИЧКА: куски нарезаны по тем же границам (верно!),
                     но source_in == timeline_start (НЕВЕРНО)
 0          69.6                              1328.8
 ├─ кусок 1 ┼─────────── кусок 2 ─────────────┼─ кусок 3 ─
```

Видео уехало влево, звук остался. **Рассинхрон = сумме выброшенных пауз.**

## 2. Почему это не поймал ни один прибор

```
            ЧТО СПРАШИВАЛИ                        ОТВЕТ
validate_ingest.py  «ингест по контракту?»        VALIDATION PASSED
prproj_verify.py    «таймлайн по плану?»          сошлось 21 из 21  ✅
pair_check          «камеры друг другу?»          37 из 37, 14.2 мс

            ЧЕГО НЕ СПРАШИВАЛ НИКТО
                    «а звучит синхронно?»         −28.7 с
```

`prproj_verify` сверяет сборку с планом, который считает **тот же планировщик**,
что паузы и выбрасывает:

```
   ингест ──► планировщик ──► план ──┐
                   │                 ├──► «сошлось» ✅
                   └──► билдер ──► таймлайн ──┘
                   ↑
          дефект ЗДЕСЬ, внутри кольца — сверка его не видит
```

> **Правило:** сверка с собственным планом — не проверка.
> Арбитр обязан брать данные **снаружи кольца** — из самих медиафайлов.
