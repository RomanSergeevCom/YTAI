# 00_init — Инициализация проекта

## Скрипты

| Скрипт | Назначение |
|--------|------------|
| `01_create_template.py` | Создать шаблон YTDEMO в ~/YTAI/ |
| `02_apply_template.py` | Применить шаблон к новому проекту |

## Использование

```bash
# Создать шаблон (один раз)
python 01_create_template.py

# Применить к новому проекту
python 02_apply_template.py --target "/Volumes/RYA Blue/YT_New_Project"
```
