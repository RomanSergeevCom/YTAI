Как запустить

Claude Code:

"Создай Assembly brief для YTCR01, проект /Volumes/RYA T7 Black/YTCR01_Arty_Dzis"

Что делает Claude:

1. Читает транскрипт с word-level таймкодами (words[]: {w, s, e})

2. Определяет блоки: Hook, Intro, Content_1…N, CTA по editing_rules

3. Размечает сегменты: USE=TRUE (в видео) / USE=FALSE (вырезать)

4. Назначает цвета по блокам, приоритеты, screen cues

5. Генерирует JSON brief + HTML review

Правило: Каждое слово попадает ровно в один сегмент. transcript = полный текст tc_in→tc_out. Нет пропусков.

Word-level tc: tc_in = first_word.s, tc_out = last_word.e + smart_padding (min(gap_to_next, 0.3))

Команды

python ~/YTAI/scripts/05_editing/0506_marker_export/export_markers_from_prproj.py --project "$PROJECT"

Шаг 2: Claude обновляет brief:

"Обнови brief из _out.json для YTCR01"

Цикл: Brief v1 → UXP Assembly → монтажёр комментирует → export _out.json → Claude → Brief v2 → UXP перезагружает → … → Brief v{final} (заблокирован)

Что делает Claude при обновлении:

1. Читает _out.json (комментарии монтажёра из маркеров Premiere)

2. Читает предыдущий _in.json (текущая версия brief)

3. Парсит editor notes: "Speaker: X | text | B-roll: Y | Notes: Z. EDITOR NOTES"

4. Применяет изменения, генерирует changelog

5. HTML review: жёлтые highlights на изменённых сегментах, CHANGED бейджи, strikethrough на удалённых
