seg_id + блок + таймкоды

Тип экрана + ссылка-якорь

Только то, что зритель увидит в итоговом видео.

max-width документа: 1600px. Три колонки одинаковой ширины (1fr 1fr 1fr).
03
Типы экранов
Визуальный формат для каждого сегмента
ТипКогда использоватьСпикерГенерация
Talking HeadHook, эмоциональные моменты, сильный текст100% кадраAE (нет)
Speaker IntroПервое появление эксперта100% + плашка внизуAE (flat bar)
Side SlideТезисы, списки, механизмы50% справаAE preset
Fullscreen 2 PointsСравнение (A vs B)Нет (или PIP*)AE preset / Gemini
Visual DemoЦепочки, схемы, маршрутыНет (или PIP*)Gemini + AE
B-roll / ФотоВизуальная метафора, конкретный объектНетGemini / сток
Step CardsПрогресс (3 ошибки, 5 шагов)100% + lower thirdAE preset
DisclaimerМед. дисклеймер (после представления)Размытый фонAE text
Важно: PIP спикера (picture-in-picture) не добавлять — визуально плохо перекрывает контент. Step Cards = lower third (3-4 сек поверх спикера), НЕ отдельный полноэкранный слайд.
04
Варианты A/B
Два варианта визуализации для ключевых экранов

Для сегментов, где визуальное решение неочевидно, создаём два варианта с переключением табами.

Колонка 2 (Экран)
Табы A/B. Каждый таб = свой CSS-мок (16:9). Переключаются JS onclick.
Колонка 3 (Производство)
Каждый вариант имеет свой Gemini промпт. Помечены "A:" и "B:" в начале.

Примеры вариантов:

  • Цепочка (горизонтальная) vs Лестница (вертикальная) — для прогрессий
  • 2 Points (два столбца) vs Side Slide (тезисы + спикер) — для сравнений
  • Split-screen фото vs Talking Head + текст — для контрастов
05
Раскадровка для Gemini
Последовательность кадров для медицинских иллюстраций

Когда нужна раскадровка: только для реалистичных анатомических/медицинских схем, которые нельзя сделать в AE пресетами. Каждый кадр — отдельная генерация в Gemini.

Структура промпта каждого кадра:

1. Референс
Что изображено на прикладываемом файле. Какую колонку/часть референса смотреть для этого кадра.
2. Как использовать
Сохрани ракурс из предыдущего кадра. Что добавить/изменить. Что оставить без изменений.
3. Задание
Конкретное описание: что нарисовать, какие цвета (#hex), какой текст, размер, стиль. 3840x2160.

Привязка к транскрипту:

КадрТаймкодСлова спикераЧто на экране
10:00"приводит к осложнениям"Здоровый пищевод, зелёный контур
20:08"язвенного поражения"+ воспаление (жёлтый)
30:15"образования структур"+ сужение (оранжевый)
.........каждый кадр = тот же ракурс + новый элемент

Workflow пользователя:

  • Клик по ссылке на референс → открывает файл + копирует путь
  • Клик "Copy" на кадре → полный промпт в буфере
  • Открыть gemini.google.com → загрузить референс + вставить промпт
  • Результат сохранить, прикладывать как "предыдущий кадр" для следующего
Kling (опционально): загрузить кадры 1→N в Kling, image-to-video, 4-5 сек. Камера неподвижна, элементы появляются / морфинг между стадиями.

08
Чеклист итерации
Проверить перед финализацией
  • Полный транскрипт в колонке 1 (не сокращённый, все слова из Assembly)
  • Метки тайминга привязаны к конкретным словам спикера
  • PIP спикера НЕ добавлен (визуально перекрывает контент)
  • Step Cards = lower third поверх спикера (3-4 сек), не отдельный экран
  • Дисклеймер расположен после Представления (не в начале)
  • CTA-экран отсутствует (видео просто заканчивается)
  • Все кнопки Copy работают (промпты копируются в буфер)
  • Ссылки на ref_images открываются / копируют путь
  • Каждый вариант A/B имеет свой отдельный Gemini промпт
  • Колонка 2 использует цвета Channel DNA (не RYA DNA)
  • Версия и время (Dubai GMT+4) обновлены
  • Футер: RYA.AE + Telegram + WhatsApp + Email (с mailto subject)
