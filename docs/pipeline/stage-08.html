Визуальный формат для каждого сегмента
ТипКогда использоватьСпикерГенерация

Важно: PIP спикера (picture-in-picture) не добавлять — визуально плохо перекрывает контент. Step Cards = lower third (3-4 сек поверх спикера), НЕ отдельный полноэкранный слайд.
04
Варианты A/B
Два варианта визуализации для ключевых экранов

Для сегментов, где визуальное решение неочевидно, создаём два варианта с переключением табами.

Колонка 2 (Экран)
Табы A/B. Каждый таб = свой CSS-мок (16:9). Переключаются JS onclick.
Колонка 3 (Производство)
Каждый вариант — один самодостаточный промпт с полным контекстом + кнопка Copy. Бейдж gemini-var-a / gemini-var-b. Текст НЕ в промпте — отдельным editor-note ниже.

Примеры вариантов:

  • Цепочка (горизонтальная) vs Лестница (вертикальная) — для прогрессий
  • 2 Points (два столбца) vs Side Slide (тезисы + спикер) — для сравнений
  • Split-screen фото vs Talking Head + текст — для контрастов
05
Раскадровка для Gemini
Последовательность кадров для медицинских иллюстраций

Когда нужна раскадровка: только для реалистичных анатомических/медицинских схем, которые нельзя сделать в AE пресетами.

Ключевые принципы промптов:

1 промпт = 1 вариант (все кадры)
Все кадры раскадровки объединены в один промпт с полным контекстом. Одна кнопка Copy. Не разбивать на отдельные куски.
Без текста в промпте
Gemini генерирует только иллюстрацию. Заканчивай: "Без текста на изображении. 3840x2160." Текст добавляет монтажёр в AE.

Структура промпта:

Контекст
Что за видео, что показываем, зачем
Референс
Что на прикладываемом файле, как использовать
Стиль
Минимализм / фото, фон #hex, без текста
Кадры 1..N
Каждый: слова спикера + что нарисовать + "приложи Кадр N-1"

Текст для AE (отдельный блок после промпта):

КадрСлова спикераТекст на экранеЦвет / шрифт
1"приводит к осложнениям""Изжога"#4ADE80 Bold 48px
2"язвенного поражения""Воспаление и язвы" + мелко "(эзофагит)"#F59E0B Bold 48px
.........Raleway, поверх иллюстрации

Workflow:

  • Открыть screen plan через open_screen_plan.command (localhost, для скачивания)
  • Drag референс из ref-block в Gemini (или click → new tab → Cmd+S)
  • Клик "Copy" на промпте → весь контекст в буфере
  • Gemini: загрузить референс + вставить промпт → генерация Кадра 1
  • Для Кадра 2+: приложить предыдущий результат + тот же промпт (Gemini видит секцию нужного кадра)
Kling (опционально): загрузить кадры 1→N в Kling, image-to-video, 4-5 сек. Камера неподвижна, элементы появляются / морфинг между стадиями.

08
Чеклист итерации
Проверить перед финализацией
  • Полный транскрипт в колонке 1 (не сокращённый, все слова из Assembly)
  • Метки тайминга привязаны к конкретным словам спикера
  • PIP спикера НЕ добавлен (визуально перекрывает контент)
  • Step Cards = lower third поверх спикера (3-4 сек), не отдельный экран
  • Дисклеймер расположен после Представления (не в начале)
  • CTA-экран отсутствует (видео просто заканчивается)
  • Колонка 2: ВСЕ CSS переменные переопределены на Channel DNA (#0A1520, #01E8AB и т.д.)
  • Gemini промпт: один блок на вариант, полный контекст, одна кнопка Copy
  • Gemini промпт заканчивается "Без текста на изображении. 3840x2160."
  • Текст для AE — отдельный editor-note с шрифтами, цветами, позицией
  • Ref images: draggable + click открывает в новой вкладке
  • open_screen_plan.command создан (localhost для скачивания)
  • Версия и время (Dubai GMT+4) обновлены
  • Футер: RYA.AE + Telegram + WhatsApp + Email (с mailto subject)
