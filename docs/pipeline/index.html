Visual overview: block table, YouTube chapters

How to run

Claude Code:

"Create Assembly brief for YTCR01, project /Volumes/RYA T7 Black/YTCR01_Arty_Dzis"

What Claude does:

1. Reads transcript with word-level timecodes (words[]: {w, s, e})

2. Identifies blocks: Hook, Intro, Content_1…N, CTA per editing_rules

3. Labels segments: USE=TRUE (keep) / USE=FALSE (cut)

4. Assigns colors by block, priorities, screen cues

5. Generates JSON brief + HTML review

Rule: Every word lands in exactly one segment. transcript = full text of tc_in→tc_out. No gaps.

Word-level tc: tc_in = first_word.s, tc_out = last_word.e + smart_padding (min(gap_to_next, 0.3))

New files after Assembly Brief

Commands

Step 1: Export markers from Premiere:

python ~/YTAI/scripts/05_editing/0506_marker_export/export_markers_from_prproj.py --project "$PROJECT"

Step 2: Claude updates brief:

"Update brief from _out.json for YTCR01"

Loop: Brief v1 → UXP Assembly → editor comments → export _out.json → Claude → Brief v2 → UXP reloads → … → Brief v{final} (locked)

What Claude does during update:

1. Reads _out.json (editor comments from Premiere markers)

2. Reads previous _in.json (current brief version)

3. Parses editor notes: "Speaker: X | text | B-roll: Y | Notes: Z. EDITOR NOTES"

4. Applies changes, generates changelog

5. HTML review: yellow highlights on changed segments, CHANGED badges, strikethrough on removed

Commands

UXP: Panel → REVIEW → Process Review

Or CLI (5 steps):

source ~/YTAI/environment/.venv_transcribe/bin/activate python 0508_review/transcribe_review_video.py --video "$VIDEO" --output "$OUTPUT" python 0508_review/export_review_docx.py --transcript "$TRANSCRIPT" --brief "$BRIEF" python 0508_review/compare_review.py --brief "$BRIEF" --transcript "$TRANSCRIPT" python 0508_review/generate_review_html.py --brief "$REVIEW_BRIEF"

Then UXP: Load Review Brief → Build Review

5 Python steps:

1. transcribe_review_video.py — Whisper transcribes the video export (word-level timestamps)

2. export_review_docx.py — DOCX table for manual review (5 columns: #, TC, text, block, comment)

3. generate_review_captions.py — SRT subtitles + transcript for Premiere

4. compare_review.py — SequenceMatcher matches edited video against Assembly brief → review_brief.json

5. generate_review_html.py — interactive HTML: 3 tables (Edited / Unused / Final Timeline), radio buttons Keep/Cut/Insert

UXP Review tab:

Process Review — runs all 5 Python steps via run_review.command

Load Review Brief — parses review_brief.json (reviewBriefParser.js)

Build Review — creates _5_Review sequence (reviewAssembler.js):

  Edited segments = Cyan, Inserted segments = Green

  DJI audio for insertions, markers with comments
